01 The rig & the placement

16 GPUs (11× CMP 100-210, 4× Tesla V100, 1× K620), each on a Gen1 ×1 riser. The pipeline's four heavy components each get their own card so nothing offloads to CPU and the transformer never reloads. The DiT gets a card to itself — it needs the whole 16 GB for activations.

02 Generation flow — temporal windowing

One card can't hold the DiT's activations for a whole 5-second clip, so it's generated in windows. Each window after the first is conditioned on the previous window's tail frames (LTX2VideoCondition) so the seams stay coherent. Prompt embeds are encoded once and reused across every window.
